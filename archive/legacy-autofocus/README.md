# Retired autofocus and positioning sources

These are the upstream beta.4 autofocus XZ package and superseded UI/position
prototype files, moved out of the active device namespace. They are retained
for inspection, not normal startup or hardware execution. Original paths and
complete earlier implementations remain available at tag `v1.0-beta.4`.

Use `devices/auto_focus`, `devices/auto_position` and the standalone
`devices/arduino_steppers` integration for maintained code. The archived sketch
is historical; do not mix its protocol with the maintained three-motor sketch.
